# coserops-missav

MissAV 篡改猴（Tampermonkey）脚本的功能需求与设计说明。

> 已提供首版可安装脚本，尚未完成真实浏览器中的网站适配验证。下文包含目标设计；当前实现范围和限制见安装说明。

## 安装与使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/index.php?locale=zh_cn)。
2. 推荐点击[安装 / 更新脚本](https://raw.githubusercontent.com/coserops/coserops-missav/main/missav-enhancer.user.js)，在篡改猴页面确认安装（维护者需先发布到 `main`）。也可在篡改猴中创建新脚本，用 [missav-enhancer.user.js](missav-enhancer.user.js) 的完整内容替换默认模板，保存。
3. 打开或刷新 `https://missav.ws/`、`https://missav01.com/` 或 `https://missav.live/` 页面，确认脚本已启用。
4. 点击页面右上方“脚本设置”，或篡改猴菜单中的“设置”。目标画质默认 360P、语言默认简体中文，选择后点击“保存并应用”。语言会保存供以后使用，当前页面有对应入口时立即切换。

当前实现使用网页 `window.player`，读取 Plyr 风格的 `player.options.quality` 并设置 `player.quality`。不能识别接口时保留网站当前模式，并显示原因；尚未实现通过点击画质菜单的兼容方案。缺少目标档位时，使用不超过目标的最高可用画质；全部高于目标时选最低档位。

语言由用户选择，默认简体中文，切换使用页面中具备 `hreflang`、明确语言名称或 `/cn` 路径、同源且内容路径一致的链接。支持样例语言入口，但不会仅凭 URL 拼接未经确认的跳转地址。没有明确匹配链接时保留当前页面。脚本会移除开头的 `dm数字` 和已知语言段来比较内容路径；该比较假设仍需站点实测。设置按钮当前固定在页面右上方。设置面板采用深色卡片布局，分为画质与语言选择、运行状态和底部操作区；窄屏自动改为单列，支持 Esc 关闭和键盘焦点提示，保存期间禁用重复操作。

回归用例可通过 `node --test tests/missav-enhancer.test.cjs` 运行，覆盖异步画质确认、实际 360P 检测、超时状态和简体中文跳转。模拟测试不等同于播放器、跨上下文方法包装、语言跳转或响应式布局已在网站验证。

## 更新与通知

当前版本 `2026.10.22.1`：新增固定更新地址、页面版本通知和篡改猴“当前版本 / 更新说明”菜单。

- **自动更新**：篡改猴从 `main` 分支的固定脚本地址检查和下载更新。用户需启用更新检查；检查周期、网络访问和权限变更确认可能影响更新时间，不保证立即安装。
- **页面通知**：新版本实际运行后，在页面右下角显示版本和更新说明。首次没有已读记录时显示“当前版本”，不误报已经升级。点击“知道了”后保存 `lastAcknowledgedVersion`，同一版本不再自动提示；未确认则下次继续提示。多个已打开页面可能各自显示，刷新后以保存记录为准。
- **手动查看**：篡改猴菜单 → “当前版本 / 更新说明”，可重新打开通知并访问本页。
- **离线订阅**：用户可以在 GitHub 仓库选择 Watch → Custom → Releases。维护者发布 Release 后，由 GitHub 根据用户通知设置发送通知；单纯推送代码不会产生 Release 通知。邮件或 Telegram 推送需要另外建立订阅渠道，本脚本不收集联系方式。

旧版手动复制安装的用户，需要先手动安装一次带更新地址的版本。浏览器未打开匹配页面时，页面通知不会运行；脚本更新后需要刷新原有页面。GitHub Raw 不可访问时，自动更新也会受影响，可使用上述手动复制方式。

发布步骤：递增脚本头部 `@version`（数字点分格式，如下一版 `2026.10.22.2`）；同步修改脚本通知文案和本节更新摘要；运行回归用例；将脚本和说明发布到 `main`。需要通知 GitHub 订阅者时，再发布对应版本的 GitHub Release。不要将更新地址改到每次变动的版本分支或标签。

通知仅保存浏览器本地已读版本，不发送遥测，不申请系统通知权限。可在篡改猴中手动检查脚本更新；发布前应实际安装一次验证更新来源，并用更高版本验证升级和首次通知。

## 1. 功能约定

| 功能 | 默认行为 | 是否需要配置 |
| --- | --- | --- |
| 防失焦自动暂停 | 页面失去焦点时，阻止网站通过播放器 `pause()` 自动暂停 | 不需要 |
| 自动宽屏 | 隐藏播放器右侧栏，让视频列占满当前布局可用宽度 | 不需要 |
| 自动设置语言 | 按保存的语言切换，默认简体中文 | 需要时修改 |
| 自动设置画质 | 优先使用 360P，可保存其他目标画质 | 需要时修改 |

### 1.1 防失焦自动暂停

参考：[missav 去掉播放暂停](example/missav%20去掉播放暂停.md)。

以参考代码为准，**不是禁止所有暂停**：页面有焦点时，用户仍可正常暂停；页面失去焦点时，拦截当前播放器的 `pause()` 调用。

- 等待 `window.player` 可用，保存原始 `pause` 方法，再包装该方法。
- 当 `document.hasFocus()` 为 `false` 时，不调用原始方法；有焦点时，保留原始方法的参数、返回值和调用上下文。
- 同一实例只包装一次；播放器被替换后，对新实例重新应用。不修改全局视频元素原型。
- 清理旧实例时，只有当前方法仍为本脚本的包装方法，才恢复原始方法，避免覆盖其他代码的修改。

该方式不能保证拦截底层视频元素直接暂停、系统媒体控制或其他途径。失焦条件不能区分调用来源，因此失焦时通过该方法发起的主动暂停也会被拦截。

缓冲、播放结束、媒体错误和浏览器后台限制不属于此功能的处理范围；不自动重播，不循环调用 `play()` 强行恢复播放。

### 1.2 自动宽屏

参考：[missav 处理为宽屏模式](example/missav%20处理为宽屏模式.md)。

定位顺序：`video.player` → 最近的 `.plyr` → 最近的 `.flex-1.order-first` 视频列 → 视频列的父布局。

- 修改样式前统一测量视频列及其兄弟元素，避免隐藏元素后引发布局变化，影响后续判断。
- 仅隐藏满足 `侧栏.left >= 视频列.right - 10` 且 `侧栏.width > 100` 的兄弟元素。
- 为视频列设置 `flex: 1 1 100%`、`width: 100%`、`max-width: none`，必要时使用 `!important`。
- 保留视频下方内容，不隐藏整个父布局，不进入浏览器全屏。
- 任一必要节点缺失时，跳过本次处理并记录原因，不能直接访问空节点。

窗口尺寸改变时，先恢复本脚本修改前的样式，再重新测量和应用；移动端堆叠到视频下方的内容不得误隐藏。只恢复本脚本拥有的改动，不覆盖网站随后更新的样式。

### 1.3 自动设置语言

语言指**网站界面语言**，不涉及音轨或字幕，可在设置面板选择并保存。

1. 目标由用户选择，默认简体中文，不读取浏览器语言偏好。
2. 页面明确为用户目标语言时不跳转；`html[lang]` 未指定文字体系时，可结合 `/cn` 路径判断。
3. 其他语言页面优先使用同源、保持当前内容的目标语言链接，支持明确语言名称、`hreflang` 或 `/cn` 入口。
4. 没有可靠目标链接时保留页面并提示，不跳回固定首页。使用会话记录防止重复跳转。

#### 网站地址与语言入口

根据用户提供的地址，脚本目标站点为 `https://missav.ws`、`https://missav01.com` 和 `https://missav.live`，已有以下入口样例。这些是用户提供的适配依据，尚未在线验证其重定向行为和页面实际语言。

| 地址样例 | 语言路径 | 设计中的识别结果 |
| --- | --- | --- |
| `https://missav.ws/dm265/en` | `en` | 英语入口 |
| `https://missav.ws/dm247/cn` | `cn` | 中文入口，简繁体需通过页面确认 |
| `https://missav.ws/dm339?localized=1` | 无 | 未指定语言，不能仅凭 URL 判断 |
| `https://missav.ws/dm285/ja?localized=1` | `ja` | 日语入口 |

语言目标保存在 `preferredLanguage` 中，默认 `zh-Hans`（简体中文）。面板提供简体中文、繁体中文、英语、日语，以及网站菜单中其余语言（固定列表）。缺少所选语言入口时保留当前页面并提示；浏览器语言不会改变用户目标。单独的 `zh` 不足以确定文字体系，需结合 `/cn` 路径或明确语言入口。

#### URL 处理规则

- `dm265`、`dm247`、`dm339`、`dm285` 是样例中的路径段，含义尚未确认，**不是语言代码**；不能硬编码“英语对应 dm265、中文对应 dm247”。
- 不把这几个入口当作所有页面的固定跳转目标，避免在视频详情页切换语言时丢失当前内容。
- 优先读取当前页面语言菜单中对应内容的目标链接。不能仅凭这四个样例就假定任意 `dm数字` 后都支持替换或追加语言路径。
- 识别语言时按已确认路由中的完整路径段匹配 `en`、`cn`、`ja`，不对整个 URL 做字符串替换，也不将内容标识中的同名文字误判为语言。
- `localized=1` 是查询参数，不能单独表示中文、英语或日语；是否用于记忆语言或其他行为需另行验证。优先采用网站语言入口提供的参数，不自行添加或删除该参数。
- 没有显式语言路径时，结合页面 `html[lang]`、语言菜单选中项等判断当前语言；信息不足或互相冲突时显示“当前语言未确认”，不盲目跳转。
- 找不到可确认且保持当前内容的目标链接时，保留当前页面并提示无法自动切换，不退回某个固定首页。

若切换需要跳转，应保留当前内容标识及仍适用的查询参数、锚点，仅使用已确认的站内语言地址。使用会话级切换记录防止循环：相同内容和目标语言已尝试切换但未生效时，停止自动跳转并提示失败。每次页面初始化重新检查页面语言，使用用户保存的目标语言。

### 1.4 自动设置画质

默认目标为 **360P**，存储值为数字 `360`，表示视频高度。保存的是偏好，不保证每个视频都提供该画质。

- 等待播放器和实际画质列表就绪，使用经确认的播放器接口设置；没有接口时，才考虑适配网站画质菜单。
- 设置面板至少包含默认 360P、已保存目标和当前视频识别到的有效画质；不支持的目标仍可显示，并标记不可用。
- 建议缺失回退规则：选择不超过目标的最高可用画质；若全部高于目标，选择最低可用画质。例如目标 360P、可用 240P/720P 时选择 240P；仅有 480P/720P 时选择 480P。
- 降级不覆盖已保存目标，下一个视频仍优先尝试用户目标。
- 只有自动画质或无法识别有效列表时，保留网站当前模式并显示原因，不声称已应用 360P。
- 只在新视频就绪或点击“保存并应用”时设置，不持续覆盖用户在网站播放器里临时选择的画质。

切换后等待最多 10 秒，通过播放器状态、菜单选中状态或已加载视频的实际高度确认结果。异步切换不会因为赋值后立即读回旧值就报错；超时显示“结果未确认”，仅接口抛出异常时显示操作失败。同一请求只赋值一次，避免重复触发切换。若接口只报告目标档位而非实际播放分辨率，应显示“已选择”，不能显示“实际播放画质”。缺失回退规则为建议方案，正式实现前需确认。

## 2. 参数在哪里填写

无需修改脚本源码，通过以下任一入口打开同一个设置面板：

- 浏览器工具栏 → 篡改猴 → 当前脚本 → **设置**，使用 `GM_registerMenuCommand` 注册入口。
- 视频区域的 **脚本设置** 按钮，仅插入一次，不遮挡播放器控制条。

```text
MissAV 脚本设置

防失焦自动暂停：自动启用，保留有焦点时的手动暂停
自动宽屏：自动启用
界面语言：[简体中文 ▼]（可选英语、日语、繁体中文等）

目标画质：[360P ▼]
当前视频：[显示实际可用画质]
应用结果：[待应用 / 已选择 / 已降级 / 应用失败及原因]

[保存并应用]  [恢复默认]
```

“保存并应用”先校验选择值、持久化目标，再应用到当前视频。没有视频时仍可保存，提示“已保存，待视频加载后应用”；保存失败时明确显示原因，不显示成功。“恢复默认”将画质重置为 360P、语言重置为简体中文，保存后应用。

### 存储约定

| 项目 | 约定 |
| --- | --- |
| API | `GM_getValue`、`GM_setValue` |
| 存储键 | `preferredQuality` |
| 类型及默认值 | 正整数，默认 `360` |
| 范围 | 当前浏览器配置中的该脚本，刷新和切换视频后保留 |
| 语言 | `preferredLanguage`，字符串，默认 `zh-Hans` |

首次无存储值时使用默认值；已有值无效时，明确提示配置异常并使用 360P。设置不与网站自身存储混用，不上传到服务器。

## 3. 初始化与生命周期

```text
页面初始化
  → 读取画质偏好，读取保存的语言目标
  → 注册设置入口
  → 匹配网站语言，必要时切换（跳转时停止本页后续初始化）
  → 等待视频、播放器和布局就绪
  → 应用防失焦自动暂停和宽屏
  → 等待画质列表，应用目标并确认结果
  → 视频切换或播放器替换时，清理旧绑定并重新应用
```

优先使用播放器事件、视频加载事件，配合限定范围的 `MutationObserver`。不要只依赖固定延时或持续高频轮询整个页面；等待必须有超时，超时后显示状态，由后续加载事件或“保存并应用”触发新的尝试。

视频源变化但播放器实例未更换时，也需重新等待画质列表。通过视频标识或任务版本防止旧异步任务影响新视频。各功能独立处理失败，不让画质识别失败阻止宽屏等功能。

## 4. 篡改猴适配约束

声明最小权限：`GM_registerMenuCommand`、`GM_getValue`、`GM_setValue`。根据提供的站点地址，首版限定为：

```javascript
// @match        https://missav.ws/*
// @match        https://missav01.com/*
// @match        https://missav.live/*
```

不绑定某个 `dm数字` 前缀，以覆盖上述不同入口；不使用所有网站通配匹配，也除上述三个域名外，不自动扩展到子域名或其他镜像域名。匹配站点页面不意味着所有页面都执行播放器处理：语言检测可独立运行，暂停、宽屏和画质功能仅在相关播放器及布局存在时执行。

参考暂停片段运行在网页上下文，而用户脚本可能运行在隔离环境。必须确认脚本能访问网页的 `window.player`；使用 `unsafeWindow` 时需声明对应权限，并验证包装方法确实影响网页调用，不能仅凭设置标记认定拦截成功。

当前目标域名与语言入口样例已记录。开发前仍需确认：播放器实例及暂停调用路径、宽屏选择器、画质接口和列表格式、语言入口的实际跳转规则、`cn` 的文字体系、无语言路径页面的实际语言及 `localized` 参数行为。参考片段中的选择器和 `window.player` 是待验证的依据，不保证网站改版后仍有效。

## 5. 验收标准

| 场景 | 预期结果 |
| --- | --- |
| 首次使用 | 目标显示 360P；可用时自动选择 |
| 修改画质后刷新或切换视频 | 保留并应用目标，不受上一视频降级结果影响 |
| 目标画质缺失 | 按确认后的回退规则选择，显示结果及原因 |
| 在网站播放器临时改画质 | 不持续改回；新视频就绪时恢复保存偏好 |
| 失焦后网站调用目标 `pause()` | 调用被拦截；切回页面后可正常手动暂停 |
| 自然结束或缓冲 | 不强制重播，不循环调用 `play()` |
| 桌面端宽屏 | 右侧栏隐藏，视频列扩展，下方内容保留 |
| 移动端或窗口尺寸改变 | 重新判断布局，不误隐藏下方内容 |
| 简体、繁体、英语和日语页面 | 匹配用户目标时不跳转，否则切换至用户所选语言，不受浏览器语言影响 |
| 提供的四种 URL 样例 | 识别英语、中文和日语入口；无语言路径不凭 `localized=1` 推断语言 |
| 不同 `dm数字` 前缀及详情页切换语言 | 不建立前缀与语言的固定映射，不丢失当前内容，不误改内容标识 |
| 无目标语言入口或切换失败 | 保留当前语言或停止重试，显示原因，不循环刷新 |
| 延迟加载、实例替换或视频源更新 | 重新应用，无重复绑定、旧任务干扰或空节点异常 |
| 接口缺失、配置异常或保存失败 | 显示明确状态和带功能名的诊断日志，不伪装成功 |
