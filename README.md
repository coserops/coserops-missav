# CoserOps MissAV 播放器脚本

**画面更宽，操作更少，播放更随心。**

减少切换窗口时的播放打断，记住常用画质和网站语言，再把视频源、画质与文件大小集中到一个下载面板里。让重复操作交给脚本，把选择留给你。

**[立即安装 · Greasy Fork](https://greasyfork.org/zh-CN/scripts/601634-coserops-missav-%E6%92%AD%E6%94%BE%E5%99%A8%E8%84%9A%E6%9C%AC)** · [GitHub 源码](https://github.com/coserops/coserops-missav) · [更多 CoserOps 项目](https://github.com/orgs/coserops/repositories)

| 想要的体验 | 脚本提供什么 |
| --- | --- |
| 切换窗口，少些打断 | 拦截已适配播放器在页面失焦时的暂停调用 |
| 自动宽屏，视野更开阔 | 隐藏符合位置条件的右侧侧栏，扩展视频区域 |
| 常用画质，不必反复选 | 保存优先画质，在实际可用档位中自动选择 |
| 熟悉的语言，一次设好 | 保存 13 种网站界面语言之一，自动尝试切换 |
| 下载选择更直观 | 汇总视频源，显示格式、画质、时长和大小，支持浏览器保存、复制链接与 FFmpeg 命令 |

> 本文依据仓库当前 [missav-enhancer.user.js](missav-enhancer.user.js) 编写，脚本元数据版本为 **`v20261023`**。功能效果取决于网站与播放器适配情况；不保证持续后台播放，不是通用广告拦截器，也不是任意视频下载工具。

## 安装与使用

1. 在浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/index.php?locale=zh_cn)。
2. 打开上方 **Greasy Fork** 页面安装脚本；也可使用仓库 `main` 分支的 [GitHub Raw 安装链接](https://raw.githubusercontent.com/coserops/coserops-missav/main/missav-enhancer.user.js)。
3. 打开或刷新下列匹配网站，确认脚本已启用。不要同时启用多个副本。
4. 点击页面右上方 **CoserOps MissAV / 播放器脚本设置**，或篡改猴菜单 → **设置**。
5. 选择画质与语言，点击 **保存并应用**，通过面板中的 **运行状态** 查看结果。
6. 在有播放器的页面，点击右侧 **视频下载** 打开独立弹窗。没有视频源时，先播放视频，再点 **重新获取**。

无法使用安装链接时，可在篡改猴中创建新脚本，用 [脚本完整源码](missav-enhancer.user.js) 替换默认模板并保存。此方式安装后也应检查更新地址是否保留。

## 播放偏好与功能边界

### 防失焦暂停与自动宽屏

这两项在检测到适配播放器或布局后自动尝试应用，**设置面板没有独立开关**。

- **防失焦暂停**：包装网页 `unsafeWindow.player.pause()`，有焦点时保留原调用，失焦时拦截。无法区分暂停来源，因此失焦时经过同一方法的主动暂停也会被拦截。底层视频元素直接暂停、系统控制、缓冲、播放结束和浏览器后台限制不在保证范围内；脚本不会循环强制播放。
- **自动宽屏**：定位 `video.player` 或 `.plyr video` 所在的 `.flex-1.order-first` 视频列，根据位置隐藏同一布局下位于其右侧、宽度超过 100px 的兄弟元素，再扩展视频列。窗口尺寸变化时重新测量。它不是浏览器全屏，也不按广告内容识别元素；网站布局变化可能导致无效果或误隐藏。

### 优先画质

默认 **360P**。选项包含默认值、已保存偏好及播放器暴露的有效档位，不承诺每个视频都有 720P 或 1080P。

- 优先选择不超过目标的最高档位；若所有档位都高于目标，则选择最低档位。
- 例如目标 360P，可选 240P / 720P 时选 240P；可选 480P / 720P 时选 480P。回退不会覆盖已保存偏好。
- 通过 `player.options.quality` 与 `player.quality` 应用，不会模拟点击网站画质菜单。
- **已选择**表示播放器属性或菜单确认了档位，不等于已确认实际播放分辨率；**当前播放**表示视频实际高度匹配。
- 最多等待 10 秒确认，超时显示 **结果未确认**，不会假报成功。可再次保存重试；没有可设置接口时保留网站当前模式。

确认后不会持续强制覆盖临时手动选择；视频、播放器实例或视频源变化时，会重新尝试应用偏好。

### 界面语言

默认 **简体中文**，不跟随浏览器语言。支持以下 13 种网站界面语言，**不改变音轨或字幕**：

| 语言 | 保存值 | 语言 | 保存值 |
| --- | --- | --- | --- |
| 繁體中文 | `zh-Hant` | 简体中文 | `zh-Hans` |
| English | `en` | 日本語 | `ja` |
| 한국의 | `ko` | Melayu | `ms` |
| ไทย | `th` | Deutsch | `de` |
| Français | `fr` | Tiếng Việt | `vi` |
| Bahasa Indonesia | `id` | Filipino | `fil` |
| Português | `pt` | — | — |

脚本从页面现有语言入口中选择目标。普通链接必须同源且对应相同内容路径，不自行拼接猜测地址；跳转尽量保留查询参数和锚点。繁体中文的特定菜单入口会调用网站自己的跳转逻辑，其行为取决于网站实现。

自动切换最多尝试两次，第二次约在初始化 3 秒后；通过会话存储防止重复跳转。未找到合适入口时保留当前页面并说明原因。手动 **保存并应用** 可重新尝试；面板中的耗时提示不是完成时间保证。

### 保存、恢复与面板操作

**保存并应用**先保存偏好，再尝试应用；保存成功不代表画质或语言切换成功，请看运行状态。无视频时也可保存，之后加载视频再应用。语言和画质分开写入，保存失败时可能已有一项生效。

**恢复默认**会将画质设为 360P、语言设为简体中文并保存应用，不清除版本通知的已读记录。设置与下载面板均可通过关闭按钮或 Esc 关闭；样式包含窄屏、短屏、键盘焦点、减少动态效果及高对比模式适配。

## 视频下载

### 先看清来源，再选择下载

下载弹窗汇总页面变量、播放器与 HLS 画质列表、视频元素、页面链接和属性、内联脚本、浏览器资源请求记录中的媒体地址。识别 M3U8、MP4、WebM、M4V、MOV 和 MPD，忽略不能直接下载的 `blob:`；不会读取跨域 iframe 内部或服务器尚未暴露的数据。

还会从内联脚本中符合规则的 UUID 推测 `https://surrit.com/<UUID>/playlist.m3u8`。这些条目先标为 **待验证**，成功解析播放列表后才取消标记；提取过程不执行内联脚本文本。

- 按完整 URL 去重并合并来源，保留不同签名参数的链接；不自动挑选“正片”，**列表可能包含预览或广告**。
- 先展示发现的链接，再解析各 M3U8 的分画质条目。不会把其中的分片、独立音轨或字幕当作完整视频列出。
- 每阶段最多并发 3 个信息请求，单次请求超时 10 秒；某个源失败不影响其余来源，原链接仍可复制。
- **重新获取**会清除解析缓存并重试；更换视频元素会清理旧面板、请求和下载任务。

### 大小与排序怎么理解

列表按**已知大小从大到小**排列，**未知大小置后**；相同大小保留发现顺序。信息陆续返回时，条目会重新排序，HLS 的估算大小也参与排序。

| 类型 | 大小的来源与含义 |
| --- | --- |
| 直链文件 | 优先读取 `HEAD` 的 `Content-Length`；不支持 HEAD（405 / 501）或无有效长度时，尝试 `Range: bytes=0-0` |
| 普通 HLS 点播 | 以分片时长总和 × 码率 ÷ 8 估算，优先平均码率，明确标注“约 / 估算” |
| HLS 多画质主列表 | 显示“按所选画质计算”，需查看具体画质条目 |
| 直播、缺少必要信息或读取失败 | 不猜测完整大小，显示“未知”；DASH 不解析大小信息 |

Range 返回 206 时读取 `Content-Range` 中的完整长度，不把 1 字节当成文件大小；服务器忽略 Range 返回完整响应时，在收到响应头后中止，不主动读取整个视频。M3U8 文本长度不等于视频大小，估算值也不等于最终文件大小。直链时长和分辨率仅在匹配的视频元素已提供信息时显示。

### 浏览器直接保存的范围

点击对应条目的 **下载视频** 才会开始保存媒体数据；打开列表会读取播放列表和文件元数据，但不会自动保存视频。

| 来源 | 当前行为 |
| --- | --- |
| MP4 / WebM / M4V / MOV 直链 | 按原格式保存，不转码 |
| 普通、已结束的 HLS 点播 | 按播放列表顺序读取分片；MPEG-TS 合并保存为 `.ts`，带单一初始化片段的 fMP4 保存为 `.mp4` |
| HLS 多画质主列表 | 先选择具体分画质条目 |
| 加密 HLS、独立音轨、字节范围、时间线切换或多初始化片段 | 不在浏览器中直接合并，改用下载命令 |
| 直播或尚未结束的 HLS、DASH / MPD | 使用 FFmpeg，不在浏览器中直接合并 |

HLS 分片即使以 `.jpeg` / `.jpg` 命名，也按列表顺序读取实际数据，不按后缀过滤或重排。保存 `.ts` 不是转换为 MP4；修改扩展名或 MIME 类型也不会完成转封装。

支持 `showSaveFilePicker` 的浏览器先选择位置，再流式写入；其他浏览器使用内存暂存，**上限 512 MiB**，超限需改用下载命令。是否支持此 API 取决于浏览器与运行环境，不代表所有平台都经过测试。

下载期间显示已传输大小与分片进度，支持 **取消下载**；30 秒无传输进展会超时。失败或取消会中止写入，不报告完整保存成功。**关闭弹窗不会停止已开始的下载**，重新打开可查看进度；刷新页面、离开页面或更换视频元素可能中断任务，不提供断点续传。

### 复制链接与 FFmpeg 命令

- **复制链接**：保留原始 URL；剪贴板不可用时选中内容供手动复制。
- **复制下载命令**：生成命令，不自动安装或运行 FFmpeg。请在安装了 FFmpeg 的 macOS / Linux 等 POSIX shell 环境执行；Windows PowerShell / CMD 不能直接套用同样的引号规则。
- 命令使用页面地址作为 Referer，通过 `-c copy` 尝试转封装为 MP4，不重新编码；`-n` 避免覆盖同名文件。发现独立音轨时加入对应输入并映射视频、音频。
- 为兼容 FFmpeg 8.x 对 `.jpeg` 等后缀 HLS 分片的检查，每个 HLS 输入在 `-i` 前带有：

  ```text
  -f hls -allowed_extensions ALL -allowed_segment_extensions ALL -extension_picky 0
  ```

  直链 MP4 与 DASH 不附加这些 HLS 参数。旧版若提示选项不存在，请升级 FFmpeg；符合浏览器保存条件的来源也可改用浏览器下载。

FFmpeg 不是万能兜底：链接有效期、登录状态、跨域策略、Referer 检查、加密密钥可访问性及编码与 MP4 的兼容性都可能影响结果；脚本不自动导出登录 Cookie，也不绕过 DRM。仅下载你有权保存的内容，勿公开分享带签名或令牌的源链接和命令。

## 本地数据与网络访问

| 存储位置 | 数据 | 用途 |
| --- | --- | --- |
| 篡改猴脚本存储 | `preferredQuality` | 优先画质，默认 `360` |
| 篡改猴脚本存储 | `preferredLanguage` | 界面语言，默认 `zh-Hans` |
| 篡改猴脚本存储 | `lastAcknowledgedVersion` | 已确认的脚本版本 |
| 网站 `sessionStorage` | `missav-language:<路径>:<目标语言>` | 防止语言重复跳转 |
| 页面运行内存 | 视频源、元数据缓存、下载进度 | 当前页面处理，非持久下载记录 |

脚本没有上传偏好或跨设备同步逻辑，不加载远程字体、图片或统计服务。**本地保存偏好不等于没有网络访问**：语言切换会导航网站；打开下载面板会请求媒体源的播放列表与文件头（必要时发起 Range 请求）；手动下载会请求视频数据；安装与更新会访问分发地址。请求仍受浏览器和源站规则约束。

声明的权限为 `GM_getValue`、`GM_setValue`、`GM_info`、`GM_registerMenuCommand` 和 `unsafeWindow`，没有申请跨域请求专用的 `GM_xmlhttpRequest` 或系统通知权限。视频请求使用浏览器 `fetch`，因此仍可能被 CORS 拒绝。

## 常见问题

| 问题 | 建议 |
| --- | --- |
| 没有设置按钮 | 检查脚本是否启用、是否在精确匹配的 HTTPS 域名下；刷新页面并检查控制台初始化错误 |
| 有设置按钮，没有视频下载按钮 | 下载入口依赖识别到 `video.player` 或 `.plyr video`；先进入播放页并加载视频 |
| 切换窗口仍暂停，或宽屏没生效 | 查看运行状态；播放器接口或布局可能已变化，底层暂停和浏览器后台限制不在保证范围内 |
| 已保存但画质未变化 | 查看“已选择 / 当前播放 / 结果未确认”等状态，确认可用档位；再次保存可重试 |
| 语言不切换 | 页面可能没有同内容的目标语言入口，或已触发防重复保护；重新保存，必要时使用网站菜单 |
| 没有链接、解析失败或大小未知 | 先播放再点“重新获取”；源站可能不暴露信息、拒绝请求或未开放响应头，未知不等于文件为空 |
| 下载按钮不可用 | 查看条目说明；多画质需选具体条目，特殊 HLS / DASH 或超内存限制需使用 FFmpeg |
| 下载 403、超时或命令失败 | 重新获取可能已过期的源，检查网络、源站限制和 FFmpeg 版本；命令不保证绕过访问限制 |

报告问题时，请提供脚本版本、域名、页面类型、浏览器与脚本管理器版本、复现步骤及控制台中 `[MissAV]` 开头的相关错误。分享日志前移除 Cookie、令牌、签名链接及其他敏感信息。

## 开发与验证

单文件 JavaScript 用户脚本，无构建步骤、无第三方测试依赖。建议使用现代 Node.js（如 22+），在仓库根目录运行：

```bash
node --check missav-enhancer.user.js
node --test tests/*.test.cjs
```

### 代码结构

- **界面与配置**：顶部集中定义运行阈值、设置与下载面板模板；偏好存储和版本提示独立处理。
- **播放器适配**：在 `document-idle` 初始化，通过 DOM 观察、视频事件和有限时轮询检测播放器，负责暂停包装、可恢复的宽屏样式及画质确认。
- **语言导航**：识别当前语言及同内容入口，用会话记录限制重复跳转。
- **下载流程**：来源发现 → 播放列表解析 → 元数据队列 → 列表排序 → 手动保存；缓存、取消控制器和请求身份检查避免旧响应覆盖新结果。
