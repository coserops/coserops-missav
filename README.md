# coserops-missav

用于 MissAV 的 Tampermonkey（篡改猴）播放器脚本，提供防失焦暂停、自动宽屏、界面语言与画质偏好设置，以及版本更新提示。

[安装 / 更新脚本](https://raw.githubusercontent.com/coserops/coserops-missav/main/missav-enhancer.user.js) · [查看源码](missav-enhancer.user.js)

> 当前脚本版本：`v20261022`。本文描述当前代码行为。自动化用例使用模拟环境，真实网站的播放器接口、语言跳转、布局及篡改猴升级流程仍需浏览器实测。

## 安装与使用

1. 安装 [Tampermonkey](https://www.tampermonkey.net/index.php?locale=zh_cn)。
2. 点击上方“安装 / 更新脚本”，在篡改猴中确认安装。链接读取公开仓库 `main` 分支的脚本。
3. 打开或刷新下列支持的网站，确认脚本已启用。
4. 点击页面右上方的“CoserOps MissAV 播放器脚本设置”，或打开篡改猴菜单 → **设置**。
5. 选择优先画质和界面语言，点击 **保存并应用**，在“运行状态”中查看实际结果。

若安装链接无法访问，也可在篡改猴中创建新脚本，将 [missav-enhancer.user.js](missav-enhancer.user.js) 的完整内容替换默认模板并保存。避免同时启用多个副本，以免重复执行。

### 支持的网站

| 域名 | 匹配范围 |
| --- | --- |
| `missav.ws` | `https://missav.ws/*` |
| `missav01.com` | `https://missav01.com/*` |
| `missav.live` | `https://missav.live/*` |
| `missav.ai` | `https://missav.ai/*` |

仅匹配上述 HTTPS 域名，不自动匹配子域名或其他镜像。不限制 `dm数字` 路径前缀；没有播放器的页面仍可保存偏好、尝试切换语言和显示版本通知。

## 功能说明

| 功能 | 当前行为 |
| --- | --- |
| 防失焦暂停 | 页面失去焦点时拦截已适配播放器的 `pause()` 调用 |
| 自动宽屏 | 隐藏符合位置条件的右侧兄弟元素，扩展视频列 |
| 界面语言 | 默认简体中文，可保存其他语言偏好 |
| 优先画质 | 默认 360P，按视频实际提供的档位选择 |
| 版本通知 | 当前版本与已确认版本不同时，在页面右下角提示 |

### 防失焦暂停

脚本通过 `unsafeWindow.player` 获取网页播放器，包装其 `pause()` 方法：页面有焦点时保留原调用，失去焦点时不执行。播放器实例更换后重新绑定，清理旧实例时仅恢复仍属于本脚本的包装方法。

此功能不能区分暂停来源，因此失焦时通过该方法发起的主动暂停也会被拦截。底层视频元素直接暂停、系统媒体控制、缓冲、播放结束及浏览器后台限制不在保证范围内。脚本不会循环调用 `play()` 或强制重播。

### 自动宽屏

脚本查找 `video.player` 或 `.plyr video`，再定位其最近的 `.plyr` 与 `.flex-1.order-first` 视频列。先测量同一父布局下的元素，再隐藏满足以下条件的兄弟元素：

```text
兄弟元素左边界 >= 视频列右边界 - 10px
且兄弟元素宽度 > 100px
```

视频列使用 `flex: 1 1 100%`、`width: 100%`、`max-width: none`，以 `!important` 应用。窗口尺寸变化后恢复脚本拥有的样式并重新测量；不进入浏览器全屏。该规则依赖网站布局，不按侧栏内容识别，网站改版后可能需要调整。

### 优先画质

画质选项包含默认 360P、已保存目标及当前播放器识别到的有效档位。脚本读取 `player.options.quality`，通过 `player.quality` 设置目标；未实现点击网站画质菜单的设置兼容方案。

目标档位不可用时，选择不超过目标的最高档位；全部高于目标时选择最低档位。例如目标 360P、可用 240P/720P 时选择 240P，仅有 480P/720P 时选择 480P。回退不会覆盖已保存偏好。

一次请求最多等待 10 秒，通过播放器属性、Plyr 菜单选中状态或视频实际高度确认结果：

| 状态 | 含义 |
| --- | --- |
| 已选择 | 播放器属性或菜单确认目标档位，不代表已确认实际播放分辨率 |
| 当前播放 | 已加载视频的实际高度与目标一致 |
| 结果未确认 | 请求已发出，但在等待时间内未确认；可保存后重试 |
| 未识别可设置的画质接口 | 保留网站当前模式 |
| 设置失败 / 无法读取画质状态 | 操作或读取出现异常，停止当前请求，可查看控制台并重试 |

每次请求只赋值一次。确认完成后不会持续强制覆盖用户临时选择；检测到视频、播放器实例或视频源变化时，会重新尝试应用偏好。

### 界面语言

语言仅指网站界面，不涉及音轨或字幕。默认简体中文，不跟随浏览器语言。下拉框固定提供以下 13 项，显示名称与代码中的网站菜单名称一致：

| 显示名称 | 保存值 |
| --- | --- |
| 繁體中文 | `zh-Hant` |
| 简体中文 | `zh-Hans` |
| English | `en` |
| 日本語 | `ja` |
| 한국의 | `ko` |
| Melayu | `ms` |
| ไทย | `th` |
| Deutsch | `de` |
| Français | `fr` |
| Tiếng Việt | `vi` |
| Bahasa Indonesia | `id` |
| Filipino | `fil` |
| Português | `pt` |

当前语言优先从 `html[lang]` 判断；缺失或仅为 `zh` 时，再参考路径中的语言段。代码将 `cn` 识别为简体中文、`tw` 识别为繁体中文。`dm数字` 不是语言代码，`localized=1` 也不能单独表示语言。

切换入口从当前页面读取，根据明确的语言名称、`hreflang` 或语言路径识别。普通链接必须同源，且移除开头的 `dm数字` 和已知语言段后内容路径一致；不会自行拼接未经页面提供的目标地址。跳转保留目标地址已有查询参数，并补充当前地址中缺失的参数（排除 `localized`）；目标没有锚点时保留当前锚点。

繁体中文菜单若带有 `@click.prevent="redirectToBaseLocalizedUrl"`，则调用该菜单的点击逻辑，由网站处理跳转，不直接访问其占位链接 `/`。这种入口的内容保留行为取决于网站实现。

自动切换在初始化和约 3 秒后的重试中检查，最多尝试两次；使用 `sessionStorage` 记录当前路径和目标语言，限制重复跳转。缺少入口时保留当前页面并显示原因。手动“保存并应用”会清除对应跳转记录、重新尝试，并优先使用目标入口，避免过时的 `html[lang]` 阻止操作。实际跳转耗时取决于网站。

## 设置与本地数据

设置面板采用深色卡片布局，包含画质、语言、运行状态与保存操作。窄屏使用单列，支持 Esc 关闭、键盘焦点提示、减少动态效果及系统高对比模式；不加载远程字体或图片。

**保存并应用**会保存所选偏好，再尝试应用。保存成功不等于切换成功，应查看运行状态。没有视频时也能保存，视频加载后再应用。保存期间禁用重复操作，失败时显示原因；语言和画质分别写入，若后续步骤失败，可能已保存其中一项。

**恢复默认**将画质设为 360P、语言设为简体中文，保存并应用；不会清除版本通知的已读记录。

| 存储位置 | 键 | 用途 |
| --- | --- | --- |
| 篡改猴存储 | `preferredQuality` | 优先画质，正整数，默认 `360` |
| 篡改猴存储 | `preferredLanguage` | 语言偏好，默认 `zh-Hans` |
| 篡改猴存储 | `lastAcknowledgedVersion` | 用户已确认的脚本版本 |
| 网站会话存储 | `missav-language:<路径>:<目标语言>` | 语言切换防重复记录 |

偏好和已读版本保存在当前浏览器的该脚本存储中，不由脚本上传。无记录时使用默认值；读取异常或偏好值无效时显示状态或记录日志。脚本声明 `GM_getValue`、`GM_setValue`、`GM_info`、`GM_registerMenuCommand` 和 `unsafeWindow` 权限，不申请系统通知权限。

## 更新与通知

当前版本 `v20261022` 的通知摘要：新增自动更新配置和版本通知。

### 用户如何获取更新

脚本的 `@updateURL` 和 `@downloadURL` 均指向：

```text
https://raw.githubusercontent.com/coserops/coserops-missav/main/missav-enhancer.user.js
```

启用篡改猴更新检查后，由扩展按用户设置检查和安装更新；也可手动检查或再次打开安装链接。检查周期、网络访问和权限变更确认可能影响更新时间，不保证发布后立即安装。旧版手动复制安装且没有更新地址的用户，需要先手动安装一次带更新配置的版本。

版本提示读取 `GM_info.script.version`，因此显示的是当前运行脚本的版本，而非远程最新版本：

- 没有已读记录时，显示“脚本当前版本”。
- 与已确认版本不同时，显示“脚本已更新到”；代码按版本字符串是否相同判断，不进行版本大小比较。
- 点击“知道了”后保存已读版本，同一版本不再自动提示；未确认则下次继续提示。
- 篡改猴菜单 → **当前版本 / 更新说明**，可随时重新打开提示。

已读状态保存失败时提示重试，通知保持可见；读取失败时在控制台记录警告。多个已打开页面可能分别显示通知，刷新后以保存记录为准。

浏览器没有打开匹配网站时不会显示页面通知，已打开页面需刷新才能运行新版。需要在不访问网站时收到发布通知的用户，可在 GitHub 仓库选择 **Watch → Custom → Releases**；维护者发布 Release 后，GitHub 根据用户通知设置发送通知。仅推送代码不会产生 Release 通知。项目当前未实现邮件或 Telegram 订阅服务。

### 维护者发布步骤

1. 更新脚本头部 `@version`，确保篡改猴将其识别为比已发布版本更新的版本；当前值为 `v20261022`。沿用日期格式时，同日迭代可使用递增后缀，并实际验证升级识别。
2. 同步修改脚本内通知摘要和 README 的版本、更新说明。
3. 运行下方回归用例，在篡改猴中验证从旧版升级、刷新后的提示及已读状态保存。
4. 将脚本和文档发布到远程 `main`；更新源保持固定，不随版本改成标签或临时分支。
5. 需要触达 GitHub Release 订阅者时，另外创建对应版本的 Release 并填写更新内容。

只有本地修改或创建 Release，而没有更新 `main` 中的脚本，不能使该自动更新源提供新版。GitHub Raw 不可访问时，安装与自动更新均可能受影响。

## 开发与验证

脚本为单文件 JavaScript，无需构建。安装 Node.js 后，在仓库根目录运行：

```bash
node --check missav-enhancer.user.js
node --test tests/missav-enhancer.test.cjs
```

用例位于 [tests/missav-enhancer.test.cjs](tests/missav-enhancer.test.cjs)，覆盖画质确认与回退、异步超时和取消、语言入口与内容路径匹配、手动语言切换，以及版本通知的显示、去重和保存失败处理。

脚本在 `document-idle` 启动，结合视频加载事件、观察 `document.body` 子树变动的 `MutationObserver` 和有限时轮询检测播放器。初始等待窗口为 15 秒，检测到播放器或视频变化、手动保存时会重置相关等待；画质确认另有 10 秒超时。DOM 变化和后续视频事件仍可触发检查。

浏览器实测需重点确认播放器接口及跨上下文方法包装、桌面与移动端宽屏、网站语言菜单跳转、设置面板可访问性，以及真实版本升级。模拟用例通过不代表所有镜像站点已适配。

遇到问题时，先查看设置面板的“运行状态”，再检查浏览器控制台中以 `[MissAV]` 开头的日志。报告问题时注明脚本版本、域名、页面类型、浏览器与篡改猴版本、操作步骤及相关错误信息。
